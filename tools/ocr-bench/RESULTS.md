- 言語: `ja` + `en`
- 対象: `gen_samples.py` が生成した合成画像 16 枚（**実写ではない**）

## 読み取れたこと

1. **文字サイズが精度をほぼ決める。** 掲示物（フォント64px）は暗所・手ブレ条件でも
   100%。一方レシート（34px）は同じ劣化で 42.2% まで落ちた。傾きや射影変形そのものは
   ほとんど効かない（`clean` と `phone_tilt` で帳票は同じ 96.8%）。効くのは
   **ボケ × 文字の小ささ** の組み合わせ。

2. **数字の `0` を英字の `O` と読む誤りが系統的に出る。** 劣化なしの状態でも発生する。

   ```
   正: 定格電圧 AC100V 50/60Hz
   誤: 定格電圧 AC1OOV50/6OHz
   正: お預り  2000円
   誤: お預り 2OOO円
   ```

   金額・型番・シリアル番号を扱うなら、数字しか来ないフィールドは
   `allowlist='0123456789'` を指定するか、後処理で `O→0` `l→1` を寄せる必要がある。

3. **画数の多い漢字・出現頻度の低い漢字で置換が起きる。**
   `邸→駅/耶/町`、`基礎→基磯`、`湿度→湿慶`、`確認→薩認`。前後の文脈を見ないため、
   辞書や候補リストとの突き合わせが有効。

4. **確信度（confidence）は誤読の検出に使える。** レシートの暗所条件は平均 0.16 まで
   落ちており、他の条件（0.77〜0.99）と明確に差がある。**0.5 を下回ったら再撮影を促す**
   といった UI 設計が実用的。

## この数字の限界

合成画像は IPA ゴシックで描いた理想的な字形に劣化を掛けたもので、実際のカメラ写真とは
以下が異なる。実写での精度はこれより低く出るのが普通。

- 印刷物の紙質・インクのにじみ、手書き文字
- レンズ歪み、局所的な白飛び・映り込み
- 背景の模様やノイズの中に文字がある状況
- 極端な斜め（この合成では最大 5 度 + 射影 4.5%）

実写での数値は `run_bench.py --image <写真> --truth <正解テキスト>` で計測する。
