■ 4. 絶対に守る規格（すべての画像に共通）
────────────────────────
1. 1枚の画像につき、1体のキャラクターと、1つの動きだけ。複数のキャラや複数の動きを1枚に入れない。見本シートや3面図のような構成にしない。
2. 横一列、同じ大きさの正方形のセル。歩兵・主人公は 256×256px、ボス・馬に乗る敵は 384×384px。画像全体のサイズは「コマ数 × セルの幅」×「セルの高さ」にぴったり合わせる。例: 8コマの主人公の画像は 2048×256px。
3. 背景は、色むらのない純粋なマゼンタ #FF00FF（R255,G0,B255）の単色。グラデーション、紫や灰色のにじみ、ビネット、ノイズ、影、床は禁止。PNGで保存し、透明にはしない。
4. 文字、番号、ラベル、キャプション、枠線、グリッド線、セルの外枠は、画像の中に一切描かない。
5. 全コマで、キャラは右向きの完全な横向き（右向き=ゲームの進行方向）。服、顔、体型、色、線の太さを、設定画から変えない。
6. 縮尺をそろえる（とても重要）: 立っているときの身長（兜の頂点から足の裏まで）は、セルの高さの約80%（256pxのセルなら約205px、384pxのセルなら約307px）。全ての画像で、この大きさにそろえる。しゃがむ、踏み込む、飛ぶ、倒れる姿勢でも、頭、胴、足の大きさは変えない（姿勢が低くなっても、キャラを縮めない）。必殺や攻撃のエフェクト（炎、雷、斬撃の軌跡）を入れるために、キャラを小さくしない。エフェクトは、キャラの大きさを変えずに、セルの内側に収める。
7. 足元をそろえる: 立っているときの足の裏（馬の場合は蹄）の位置は、全てのコマで同じ高さ（セルの上から90%の位置。256pxのセルならy=230、384pxのセルならy=346）。全てのコマで、人物は、セルの左右の中央に置く。ジャンプ・ダウンなどで足が浮くコマは、足の位置が自然に上がってよい。
8. 余白: 人物、武器、エフェクトは、セルの端（上、左、右）から16px以上離す。隣のコマにはみ出さない。隣のコマの手足や武器の一部が見えてはいけない。
9. 空のコマを作らない。全てのコマに、全身を描く。
10. 体から離れて浮く部品（矢、弾、武器の破片など）は、描かない。飛び道具は、発射の瞬間でも、体の近くに描く。
11. 隣り合うコマの違いは、少しずつにする。動きが滑らかに続くこと（約12コマ/秒で再生される）。待機は、4コマとも少しずつ違う姿勢（呼吸、布や髪の揺れ）にする。
12. 攻撃の動きは、「構え→振りかぶり→命中の瞬間→余韻」の順にして、命中の瞬間を、全体の真ん中あたり（6コマなら3〜4コマ目）にする。

■ 5. 1枚ごとの作業の流れ（必ずこの順番で、1枚ずつ）
────────────────────────
1. 参照画像（設定画）を開く。必要なら、見本の画像も開く。
2. 「11_プロンプト集」の、共通スタイル＋キャラ記述＋動きの定義＋レイアウト指示を貼り合わせて、画像を1枚生成する（一度に複数枚をまとめて生成しない）。
3. 下の「自動チェック」を実行する。NGが出たら、原因に合わせて指示を足して、作り直す（1枚につき最大3回まで）。
4. 目視で確認する（顔・服・武器が設定画と違わないか、足元が揃っているか、隣のコマの欠片が見えないか）。
5. 合格したら、フォルダに保存する（ファイル名は、下の「7. 納品物」のとおり）。3回作り直しても合格しない場合は、いちばん良いものを保存し、進捗表に「要注意: 理由」と書く。
6. 進捗表（下の「9」）に追記する。


■ 自動チェック（そのままPythonで実行できます）
```python
import numpy as np
from PIL import Image


def check_strip(path, n, cell, grounded=True):
    """path: 画像ファイル, n: コマ数, cell: 256 または 384, grounded: 足が地面に着く動きなら True"""
    a = np.asarray(Image.open(path).convert('RGB')).astype(int)
    H, W, _ = a.shape
    out = []
    if (W, H) != (n * cell, cell):
        out.append(f'NG サイズ違い {W}x{H}（正しくは {n*cell}x{cell}）')
    d = np.abs(a[..., 0] - 255) + a[..., 1] + np.abs(a[..., 2] - 255)  # マゼンタからの距離
    pure = (d < 40).mean()
    out.append(f'{"OK" if pure > 0.5 else "NG"} 純マゼンタの割合 {pure:.0%}（50%未満はNG: 背景に色むらや絵が広がりすぎ）')
    fg = d > 150
    bottoms, heights = [], []
    for i in range(n):
        c = fg[:, i * cell:(i + 1) * cell]
        ys, xs = np.where(c)
        if len(ys) < 3000:
            out.append(f'NG コマ{i+1}: 空、または小さすぎる'); continue
        bottoms.append(ys.max()); heights.append(ys.max() - ys.min())
        m = 16
        if xs.min() < m or xs.max() > cell - 1 - m or ys.min() < m:
            out.append(f'NG コマ{i+1}: 絵がセルの端から16px以内にある（はみ出し）')
    if bottoms and grounded:
        g = int(cell * 0.9)
        if max(bottoms) - min(bottoms) > 12:
            out.append(f'NG 足元の高さがコマごとにずれている（{min(bottoms)}〜{max(bottoms)}px）')
        if abs(int(np.median(bottoms)) - g) > int(cell * 0.06):
            out.append(f'NG 足元が目標（約{g}px）から遠い（実際 {int(np.median(bottoms))}px）')
    if heights:
        r = np.median(heights) / cell
        out.append(f'{"OK" if 0.55 < r < 0.95 else "NG"} 人物の高さ（中央値）はセルの{r:.0%}（立ち姿の目標は約80%。しゃがむ動きは低くてよいが、極端に小さい/大きいのはNG）')
    return out


# 使い方の例:
# for line in check_strip('真田幸村_歩き_8コマ_v2.png', 8, 256): print(line)
```
※このチェックで合格しても、文字が入っていないか、顔や服が設定画と違わないかは、目視で確認してください。

■ 6. これまでの失敗例（繰り返さないでください）
────────────────────────
・1枚に複数のキャラや動きを入れて、コマが小さくなった。文字（"Idle" など）や枠線が絵の中に混ざった。
・背景が紫がかった灰色になった。空欄のコマができた。
・隣のコマの足や武器の一部が、セルの端にはみ出して見えた。
・動きごとに、キャラの大きさがバラバラだった（待機は大きく、攻撃や必殺は半分の大きさ、など）。ゲーム内で、動きが切り替わるたびに、キャラが縮んだり膨らんだりして見えて、いちばん目立つ問題だった。
・歩きが、全コマ「右足が前、左足が後ろ」のままで、足が入れ替わっていなかった。
・体から離れて、足先や槍の先が浮いていた。
・待機の4コマが、全く同じ絵だった。
