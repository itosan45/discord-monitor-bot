# 動作の再発防止

ユーザー指摘の誤りは、立ち絵の武器角度や全高の差だけをアニメーションとして扱うこと。脚・骨盤・支持足・重心の変化がないと、横スクロールゲームで歩行や攻撃に見えない。

- 最新11を読んだ後もtasks-v2.jsonのmotionに旧03bが残っていた。3/7の通過を4/8の足寄せと混同する原因になるため、最新11の8段階に同期。既存の完了判定は変更せず、変更一覧をresume-spec-sync-log.jsonへ保存。
- 歩きは1/5の近い腿と膝の前後、3/7の遮蔽の反転、両足の右向き、低い腰を別々に目視する。画面上の前後の足位置だけで左右交代を判定しない。
- 攻撃は予備動作・打撃瞬間・振り抜き・回収を全コマと確認GIFで追う。突きは直線の踏み込み、上下斬りは脚と腰の上下運動、薙ぎは腰の捻り、回転は踏み替えを確認する。
- 自動チェック合格と動作合格を別項目で記録する。修正回数上限後の動作不足は要注意として理由を明記する。
- 防御と回避は攻撃や被弾を流用せず、待機との接続、主武器の保持、体格に合う足運びを確認する。

## 落とした武器と身体の接地
原因: 全前景の最下点で接地すると、身体より下に離れた刀がある倒れコマで身体が浮く。対策: 新しい正規化記録に薄い武器を除く身体最低点の推定を記録し、目標より12px以上ずれたら自動QAでNGを出す。刃と身体をPythonで別移動せず、画像生成で落とした武器を身体の接地線へ合わせる。空中コマは全身単位の縦オフセットを記録して身体の浮きを保持する。
