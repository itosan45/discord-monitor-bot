# RIFE補間の実験(幸村の歩き) 2026-10-14

- 元: `assets/sprites/真田幸村_歩き_6コマ.png`(256×256×6、純マゼンタ背景)。**元の絵は変更していない**。
- 結果: `真田幸村_歩き_12コマ_RIFE実験_v1.png`(3072×256、偶数番=元の絵、奇数番=RIFEの補間コマ。最後→最初も補間して循環)。**ゲームには組み込んでいない**(実験のみ)。
- 比較動画: `compare_yuki_walk.mp4`(左=元6コマ10fps、中=単純クロスフェード12コマ、右=RIFE 12コマ20fps)。`legs_orig_vs_rife.png`は脚の拡大(上段=元、下段=補間)。
- 使ったモデル: RIFE v4.25(HolyWu/vs-rife のフローネット重み)。CPUのみ・PyTorch。`rife_core.py`はモデル定義を読んで確認し書き写したもの(外部コードは実行していない)、重みは`weights_only=True`で読込。6組の補間は約1秒。
- 所見: 上半身・旗・槍・陣羽織は崩れず、脚も歩幅の途中の形になった。気になる点は、槍の石突きが一部の補間コマで二重にぼやける、小さなゴミ点が出る場合がある。v4.22(別形式の重み)は読み込みに失敗(未対応)。
- 未確認: ゲーム内での動き・接地位置・当たり判定との相性、他キャラ・攻撃コマ。
