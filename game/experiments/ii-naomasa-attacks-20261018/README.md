## 目視と自己評価

- 16コマ版は、低い横薙ぎの後に柄頭を前上へ向け、刀身を後方へ逃がす握り替えを入れた。初回v1は刃先主導に読め、フレーム9の左下に孤立した刀片も出たため、採用候補にせず保持。v2はその刀片を除き、柄尻を先に出す軌道へ調整した。
- 14コマ版は、片膝を上げて蹴り、足を戻して構え直し、踏み込み突き、回収の順。v2はv1と画素が同一で、再処理後も境界QAが通ることを記録した版。新しい動きの追加ではない。
- 接地・全コマ差分・セル内余白は合格。静止一覧とGIFを目視した。柄頭の厳密な接触点、武器寸法の既存絵とのピクセル一致、当たり判定、ゲーム再生速度、左右反転、実機表示は未確認。接触/前進数値は絵の見た目からの候補で、ゲーム判定値ではない。
- 画像生成AIの4×4ポーズシートをセル抽出・背景除去・均一縮尺・配置合成した候補で、純手描きではない。境界につながった小さな生成断片のみ除去し、人物/武器の主連結成分は削っていない。元画像は`source_*grid-*.png`、処理は`pack_candidates.py`。
- `assets/sprites/`、依頼一覧、ゲームコードは変更していない。Claudeが原画採用・組み込みを判断するまで候補扱いを維持する。
