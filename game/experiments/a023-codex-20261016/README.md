## 生成・配置の記録
built-in image_genを計3回使用。Geminiは呼んでいない。幸村1コマを画風のみの参照に使用し、赤備え/鹿角/顔は流用しない指示。大筒は緑青の青銅、補強輪、丸い後端、木の砲架と2輪、紺の砲手2人、点火棒と込め矢。大将は紺と金の兜/具足/陣羽織、腰刀、白紙の采配、全コマ右向き・4段階・固定接地・純マゼンタ・文字無しを指示。

最初の大筒は発射コマで砲身が短縮し、1輪に見えたのでそのまま不採用。追加の局所AI編集で奥の車輪を生成し、元の前景を保持して背景だった領域へ輪を合成。砲身・砲架・輪・砲手の待機絵を固定して4コマへ組み直し、2の点火役、3の火炎白煙、4の白煙だけ生成結果から合成。3は固定絵を左へ14原画px(納品サイズ約8px)移動して反動。純手描きとは主張しない。

大将は2x2原画を同倍率で縮小して横4コマ化。3の紙房が境界を越えた領域を回収し、4へ混入した同領域を除去。v1の小片と鞘の端切れをv2で修正、v3で2/3の接地を1px補正。候補は既存画像を上書きしていない。
