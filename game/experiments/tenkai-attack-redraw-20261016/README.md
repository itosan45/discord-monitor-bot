# 天海の攻撃モーション描き直し候補

Claudeのデモ確認で通常攻撃が硬く、跳躍叩きつけが小さく地面を離れないとの指摘を受けたため、画像担当として作った途中候補。元のAI仮PNGを上書きしていない。Claude側は鎖鉄球をコードで描画する方針のため、ここでは人物の体モーションだけを制作した。

## 候補

- `tenkai-normal-attack-body-candidate-v3.png`: 6コマ、1800×430、300×430/コマ。構え→溜め→捻り→踏み込み→振り抜き→構え。
- `tenkai-leap-smash-body-candidate-v3.png`: 5コマ、1500×430、300×430/コマ。沈み込み→離陸→頂点→降下→着地。2〜4コマは足が地面から離れる配置。
- `*-preview.gif`と`motion-review.html`: 動きの確認用。
- `qa-candidates-v3.json`: 寸法、前景範囲、コマ端接触、SHA-256。
- `tenkai-*-keyframes-raw.png`: built-in image_genの未加工キー姿勢シート。

## 制作と確認

built-in image_genで既存の天海絵と戦闘スプライトを参照し、通常攻撃・跳躍攻撃の体のキー姿勢を生成。独立した人物だけを抽出して各コマに配置し、背景を純マゼンタへ統一した。純手描きとは主張しない。鎖鉄球は含まないので、Claudeの別描画と合わせて確認する必要がある。

両シートを静止で目視し、6/5コマの順序、全身、足位置、セル端への前景接触なしを確認した。これは素材候補の目視であり、ゲームへの組み込み・左右向き・当たり判定・実デモ・実機での合格ではない。Claudeへ候補を返し、鎖鉄球表示を合わせた拡大デモで最終判断する。v1/v2の初回配置候補は隣接コマ由来の切れ端が出たため不採用、v3で各人物の独立領域から再構成した。
