### 参考資料と読み取った方針
- [SNK公式 覇王丸の技一覧](https://samuraianiv.snk-corp.co.jp/english/character/haohmaru/index.php)には旋風・上昇弧・地を払う斬りなど複数の軌道の技が別々に載る。**作業上の推論:** 同じ斬撃の光違いではなく、武器の軌道・腰の向き・踏み込み・戻りを変えれば別技として読める。
- [The Spriters Resource: Capcom vs. SNK 2 覇王丸シート](https://www.spriters-resource.com/playstation_2/capvssnk2/asset/183174/)は攻撃などのフレームを含む公開スプライトシート。画像の利用・複製はせず、フレームで予備動作/当たり/回復が読み分けられる構成を参考にする。ページ上の元画像は直接取得制限(403)があり、細部の全フレーム目視はしていない。
- [SNK公式 狂死郎の紹介](https://samuraianiv.snk-corp.co.jp/english/character/kyoshiro/index.php)と[公式紹介(日本語)](https://www.snk-corp.co.jp/official/samuraispirits/characters/kyoshiro.php)では、薙刀と舞踊を合わせた型が説明される。**作業上の推論:** 薙刀は刀の短い斬撃と区別し、両手の握り幅・長い円弧・足運びを大きくする。
- [SNK公式パッチノート](https://www.snk-corp.co.jp/kr/games/samuraishodown/ss_patch_2.10_eng.pdf)が攻撃の発生/有効/硬直差を個別に調整している。**作業上の推論:** ゲーム割当用シートにも溜め、接触、反動、戻りを別ポーズとして含める。
- 参考は攻撃の組み立てだけ。既存ゲームの人物・ピクセル・コマを複製していない。
