# A-024 天海の攻撃描き直し候補

Claudeのデモ確認で通常攻撃は鉄球を振らず立ったまま、跳躍叩きつけは小さく地面を離れないと報告されたため、画像担当として作成した候補。既存AI仮PNGは上書きしていない。`game/ASSET_REQUESTS.md` の最新仕様に合わせ、両方とも300×430セルを6コマ、全コマに鎖と鉄球を含む。

## 候補

- `南光坊天海_通常攻撃_6コマ_v2.png`: 1800×430。低い構え→頭上で振り始め→胸の高さで前へ振る→鎖を伸ばして前方へ→引き戻し→構え。
- `南光坊天海_跳躍叩きつけ_6コマ_v2.png`: 1800×430。深く屈む→離陸→最高点→降下→鉄球を地面に打ちつける→構え。
- `*-preview.gif`と`motion-review.html`: 動きの確認用。
- `qa-v2.json`: 寸法、コマ接触、接地アンカー、SHA-256。
- `*-keyframes-raw-v1.png`: built-in image_genの未加工キー姿勢シート。

## 制作と確認

built-in image_genで既存の天海待機・攻撃スプライトを参照し、人物・衣・数珠・鎖鉄球のキー姿勢を生成。各姿勢を分離し、同一縮尺で300×430セルへ配置して背景を#FF00FFにそろえた。純手描きとは主張しない。

静止シートで全12コマ、左右セル境界、鉄球の有無、人物と武器の欠け、跳躍中の接地線を確認。これは素材候補の検品であり、Claude側のコード組み込み、鉄球軌道・発射時刻合わせ、実デモ/左右向き/当たり判定、実機確認は未完了。候補としてClaudeへ共有し、拡大デモのレビューを依頼する。候補名にv2が含まれるが、`game/experiments/`内の途中成果であり完成納品とは区別する。
