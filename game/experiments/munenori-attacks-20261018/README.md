# 柳生宗矩 追加攻撃候補（未組み込み）

Claudeの指定で既存3種に加える居合斬り・二連斬りを作成。これは原画候補で、完成納品・ゲーム合格ではありません。コード/アトラスは未変更。

## 候補と動作配分

- `柳生宗矩_居合斬り_12コマ_v1.png`: 1-2予備、3-5踏み込み/抜刀、**7当たり**、8-9振り抜き、10-12納刀/残心。前進提案22px。
- `柳生宗矩_二連斬り_20コマ_v1.png`: 1-2予備、3-5袈裟斬りの準備、**6一段目当たり**、7-8振り抜き、9-10切り返し、11-13逆袈裟の準備、**14二段目当たり**、15-16振り抜き、17-20残心。前進提案30px。

## 参考分析

公開されている Samurai Shodown の覇王丸・柳生十兵衛・橘右京のシート/技資料を動きの参考にした。居合は納刀姿勢から腰と膝を締め、短い踏み込みで抜き、当たり後に刀先を制御して残心へ移る。二連斬りは一段目の袈裟から一度腰を戻して反対側へ切り返し、二段目後に低く構える。重い攻撃の予備と残心にコマを配し、効果線で速さを偽装しない。原作画像や固有ポーズは複製していない。参考先: [The Spriters Resource: Haohmaru (Samurai Shodown)](https://www.spriters-resource.com/game_boy_gbc/samuraishodown/asset/100902/), [The Spriters Resource: Ukyo (Samurai Spirits)](https://www.spriters-resource.com/nes/samuraispiritsbootleg/asset/278276/)。公開ページは参考資料の所在確認に使用。

## 画像制作・QA状態

Built-in image generationで全身姿勢シートと局所4コマ補修を生成し、各コマを配置して512x384横ストリップに合成。純手描きではない。背景キーを純RGB(255,0,255)へ整え、コマ端接触・寸法・接地・連番GIFを確認する。各PNGの計測とSHA-256は対応する `*-qa.json` に記録。

刀身長の全コマ厳密計測と画面上の動作/当たり判定の実ゲーム確認は未了。Claude側の組み込みレビュー後に必要な修正を行う。待機比の実ゲーム縮尺はClaudeの `check_sprite_scale.py` で確認する。
