# 柳生宗矩 追加攻撃候補（画像レビュー用）

Claudeの最新指定に基づき、既存攻撃と重複しない居合斬り・二連斬りを原画候補として作成。候補PNGはv3/v2。v1は画像端に跨るコマを含む不採用試作、v2居合は枠内だが準備と残心の姿勢差が小さいため不採用。既存PNGを置き換えていない。

## 候補

- `柳生宗矩_居合斬り_12コマ_v3.png` — 512×384×12。1-4構え/柄へ手を運ぶ/沈み/踏み出し、5-8抜刀〜一閃と振り抜き、9-12減速・納刀・残心。想定当たりは7コマ目、前進案22px。
- `柳生宗矩_二連斬り_20コマ_v2.png` — 512×384×20。1-2予備、3-5袈裟の溜め、6一段目当たり、7-8振り抜き、9-10切り返し、11-13逆袈裟の溜め、14二段目当たり、15-16振り抜き、17-20残心。前進案30px。

## QA

各技の `*-qa.json` に寸法、セル寸法、フレームごとの中央シルエット高、四辺2px内の接触、当たり番号、前進案、SHA-256を記録。 `*-contact.png` は全コマ静止一覧、`*.gif` は約12〜16fpsの全コマループ。 `*-motion-diff.json` の隣接コマ画素差は同一絵の重複検出用の補助値だけで、動作品質の合格判定ではない。

現在確認済み: 12/20コマを順番どおり静止一覧で確認。全セル512×384、背景は純RGB(255,0,255)、四辺2px内接触なし。中央領域の高さは居合中央値約188px、二連中央値187px。連番GIFを作成。

要レビュー: 全モーションの実速度目視、納刀の刀身整合、全フレームの刀身長の厳密一致、待機比の実ゲーム縮尺、当たり/前進量は未確認。数値チェックと止め絵では完成合格にしない。ゲーム組み込み・コード変更は未実施で、Claude担当。これらは組み込み後の本編・全編デモ・一体デバッグで確認してから合格扱いにする。AI局所生成と配置合成であり、純手描きではない。

## 参考分析

Samurai Shodown の公開素材を動きの参考にした。見比べる観点は、抜刀前の膝/腰の沈み、刀の抜き始めから当たりまでの短さ、振り切った刀先を止めて残心へ移る順序。二連は袈裟の後に胴を戻し、反対側から逆袈裟へ切り返す。ここではゲーム仕様の12/20フレームに当たり1コマを明示して再配分した。公開ページの一部は取得が拒否され、原作の厳密なフレーム数を読み取れたとは主張しない。画像・固有ポーズは複製していない。参照: [覇王丸の公開シート](https://www.spriters-resource.com/game_boy_gbc/samuraishodown/asset/100902/)、[橘右京の公開シート](https://www.spriters-resource.com/nes/samuraispiritsbootleg/asset/278276/)、[柳生十兵衛の技一覧](https://snk.fandom.com/wiki/Jubei_Yagyu/Move_List)。
