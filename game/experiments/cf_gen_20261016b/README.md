# Cloudflare Workers AI の試し: 大谷吉継・島津義弘の会話胸像(2026-10-16)

`game/tools/cf_image.py --network-secret --steps 8`(seed なし)。生成は6回、すべて成功(429 なし)。

- 使えそう: `大谷吉継_会話胸像_cf_v3_切り抜き560.png`・`島津義弘_会話胸像_cf_v3_切り抜き560.png`
  - 既存の肖像(gfx/port_*.webp と同じ560×560・透明背景・左向き)に合わせて、緑の背景の元画像(`*_cf_v3.png`)から、外側につながる緑だけを透明にして作った。
  - 島津: 右肩の上に出ていた、文字のような模様の金具を消した。胸の「丸に十字」は残した。
  - 大谷: 白い頭巾と覆面で目元だけが見える。絵柄は既存の肖像(重厚な劇画調)に近い。
- 使わない:
  - 大谷 v1(若いアニメ調で絵柄が合わない)
  - 大谷 v2・島津 v1・v2(`--magenta` の背景判定が、四隅に掛かった鎧や頭巾を背景と誤認して、穴が開いた)
- 分かったこと: 胸像のように絵が画面の下の角まで届くものは `--magenta` を使わず、はっきりした緑の背景で作ってから、外側からつながる部分だけを抜く。
- 用途: 会話の肖像の候補、画像担当(A-030)の見た目の参考。ゲームにはまだ組み込んでいない(大谷・島津は、動きの絵が届くまで出ない)。
