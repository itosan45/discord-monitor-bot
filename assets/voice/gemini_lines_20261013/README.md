生成条件: Google AI Studio の音声生成(Gemini TTS)、声は無料の Algenib、Temperature 1。
スタイル指示(勝鬨): 「日本語。戦国武将が、敵の大将を討ち取った直後に、勝ち誇って、腹の底から大声で力強く言い放つ。威厳のある、低く太い男性の声。短く、鋭く、迫力をもって。」
語尾を伸ばした版(teki_nobi_*)のスタイル指示: 「日本語。戦国武将が、敵の大将を討ち取った瞬間に、勝ち誇って、腹の底から大声で雄叫びを上げる。「討ち取ったり」の最後の「り」を、息の続く限り長く長く伸ばして、力強く響かせる。威厳のある、低く太い男性の声。」 本文は a が「敵将、討ち取ったりーーーーー！」、b が「敵将、討ち取ったりぃぃーーーーーーーーっ！」。
ブロック分けの版(teki_blk_*): 同じ声 Algenib を話者1・話者2の両方に指定。ブロック1(「敵将、」)のスタイル「日本語。戦国武将が、腹の底から大声で、短く、はっきり、歯切れよく言い放つ。抑揚を抑えて一本調子で、音を伸ばさない。威厳のある、低く太い男性の声。」 ブロック2(「討ち取ったりーーーーーーー！」)のスタイル「日本語。戦国武将が、敵の大将を討ち取った瞬間に、腹の底から大声で言い放つ。感情の起伏を抑えて力強く、「討ち取ったり」は一気に言い、最後の「り」の母音だけを、息の続く限り、音程を変えずに長く伸ばし続ける。威厳のある、低く太い男性の声。」
途中で試した単一ブロックの版(「抑揚は少なく」とだけ指示)は、「敵将」は約0.65〜0.7秒に縮んだが語尾の伸ばしがほぼ消えたので不採用。(伸ばす前の teki_a/b/c のスタイル指示は記録し忘れた。同じ系統の指示。)

聴き比べ用: compare_tekisho_yuki_prev_blkA_blkB.mp3(直前の伸ばしa→ブロック分けa→ブロック分けb[ゲーム採用]、幸村の高さ)、tekisho_6heroes_blk_b.mp3(6人、採用中のブロック分けb)、compare_tekisho_nobi_yuki_owner_b_nobiA_nobiB.mp3(オーナー録音→伸ばす前→伸ばしa→伸ばしb)、compare_tekisho_yuki_old_b_a_c.mp3(伸ばす前の比較)、compare_kachidoki_old_b_a.mp3(勝鬨: 旧→b→a)。各音の間は0.8秒。

## ゲームへの入れ方
`python3 game/tools/import_generated_lines.py [teki_?] [kachi_?]`  → そのあと `cd game && python3 build.py`
- 引数なしなら teki_blk_b と kachi_b。別のテイクにしたいときは `... teki_blk_a kachi_a` のように指定する(語尾を伸ばす前に戻すなら `... teki_b`、直前の伸ばし版なら `... teki_nobi_a`)。
- `vo`(6人の主人公の「討ち取ったり」)は主人公ごとに音の高さを変える(従来の v5 と同じ比率)。
- `uv.victory`(勝鬨の音頭)は、次の「えい・えい・おー」(3.2秒後)に被らないよう約2.7秒に速度をそろえる(採用の kachi_b は 3.01 秒→×1.11→出力 2.76 秒。従来の録音版も 2.78 秒)。

## 元に戻す
オーナー録音は `assets/voice/user/` に残っている。戻すには次の2つを実行して再ビルドする。
```
python3 game/tools/import_tekisho_vo.py      # vo を「敵将、討ち取ったり」オーナー録音版(v5)に戻す
python3 game/tools/import_user_voice.py      # uv.victory を「者ども、勝ち鬨をあげよ」オーナー録音版に戻す(charge/hey/seiya も同じ内容で作り直される)
cd game && python3 build.py
```
